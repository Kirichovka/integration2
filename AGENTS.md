# Project instructions

- Use English for new documentation, project notes, issues, pull requests, and commit messages.
- Preserve imported source documents in their original languages. Store translations separately.
- Use models/machine-vision/ as the current model directory. Older cloud model copies were removed after comparison and remain recoverable from Git history.
- Model saves use contributors/<GitHub login> branches. Follow tools/TEAM_WORKFLOW.md; only the main-branch merge automation regenerates model checksums in team mode.
